The API reference is generated by TypeDoc from the TSDoc comments of the three entry points, and published next to
these docs:

**[bvh.docs.pmnd.rs/api](https://bvh.docs.pmnd.rs/api/)**

| Entry point | Reference |
| --- | --- |
| `@pmndrs/bvh` | [modules/_pmndrs_bvh](https://bvh.docs.pmnd.rs/api/modules/_pmndrs_bvh.html) |
| `@pmndrs/bvh/three` | [modules/_pmndrs_bvh_three](https://bvh.docs.pmnd.rs/api/modules/_pmndrs_bvh_three.html) |
| `@pmndrs/bvh/worker` | [modules/_pmndrs_bvh_worker](https://bvh.docs.pmnd.rs/api/modules/_pmndrs_bvh_worker.html) |

Only what the entry points export is listed (`src/index.ts`, `src/three/index.ts`, `src/worker/index.ts`). Each name
there is exported on purpose; anything else is internal.

## Building it locally

```bash
pnpm docs:api        # writes api-docs/, open api-docs/index.html
```

The configuration is `typedoc.json` at the repository root.
