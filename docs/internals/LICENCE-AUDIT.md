# Licence audit (D8)

2026-11-15, for the 0.1.0 release.

**Verdict: passes, after the fixes below.** Everything in the package that comes from someone else comes from MIT code (tinybvh, HIPRT, three-mesh-bvh, three.js) or is the Emscripten runtime linked into the `.wasm` (MIT, NCSA, CC0, Apache-2.0 with LLVM exceptions). Nothing comes from a repo without a licence: Meister's PLOC and PRBVH, AlanIWBFT/CWBVH and kishimisu's sort are not named anywhere in the code, and the CWBVH spike stayed in ddgi. NexusBVH (Apache-2.0) and HIPRT's PLOC kernels were read about, not copied. Every licence text ships in `licenses/`. Before this audit, seven shipped files held ported code without the licence notice in the file, and some of that code was missing from `THIRD_PARTY.md`. Those gaps are now fixed. One question is left for Dennis: a dev-only bench script reproduces code from homefig (see "Left").

## Dev-only code (not shipped)

- `compare/gpu/gpu-sdf.ts` copies three-mesh-bvh's `webgpu_sdfGeneration` kernel, which is MIT. It is listed in `THIRD_PARTY.md`.
- `examples/three/*` contains 14 ports of three-mesh-bvh `v0.9.18` examples, plus `examples/compare/skinned`. All of them are MIT. `select.ts` carries the full text. The seven ports that didn't name their source now do, and the `THIRD_PARTY.md` row lists all 14.
- `bench/query-parity.ts` reproduces three-bvh-csg's `collectIntersectingTriangles` (MIT, (c) 2022 Garrett Johnson; the row is **added**). It also reproduces homefig's capsule controller (see "Left").
- `tests/gpu/pages/trace-bench/*` and `tests/gpu/pages/trace-oracle/cases.ts` are ported from webgpu-ddgi and gpu-ray-provider, which are Dennis's own projects.
- The compared libraries are dependencies, not copies: three-mesh-bvh (MIT), bvh-tree (MIT), bvh.js (MIT), Babylon.js (Apache-2.0) and Rapier (Apache-2.0). Test scenes are downloaded and not committed (CC BY, plus the Intel Sponza terms). All of these are listed.

## Fixed

- Added a `/*! */` header with the upstream MIT text to `src/hploc-cpu.ts` (tinybvh), `src/lbvh-cpu.ts` (HIPRT), `src/query/shapes.ts` and `src/query/cpu-mesh-bvh.ts` (three-mesh-bvh and three.js), `src/query/debug.ts` and `src/query/three-mesh-bvh-format.ts` (three-mesh-bvh), and `src/trace/wgsl.ts` (three.js). These are comments only. `pnpm lint` and `pnpm build` pass, and all seven headers are at the top of their files in `dist/`.
- `THIRD_PARTY.md`: added rows for three-mesh-bvh's shape math, casts and debug functions, for three.js's math, and for three-bvh-csg in the bench. Named `lbvh-cpu.ts` and `hploc-cpu.ts` and their headers. Listed all 14 ported examples.
- `licenses/hiprt.txt` pointed at `packages/bvh/src/...`, the path in the old monorepo. It now names `src/gpu-lbvh-wgsl.ts` and `src/lbvh-cpu.ts`.
- `examples/three/{batchedMesh,clippedEdges,collectTriangles,edgeIntersect,lineIntersection,triangleIntersect,voxelize}/main.ts` each got one line naming the upstream example and its licence.

## Left

- **homefig code in `bench/query-parity.ts`.** `controller()` reproduces the arithmetic of homefig's `collisionCheck` and `floatingCheck` (`bvh-ecctrl.tsx`). homefig is not public, and the licence of its code is not known here. This file is dev-only and doesn't ship, but the repo is public. Dennis needs to confirm this may be published, or the function should be rewritten as a generic capsule test.
- **`scripts/verify-artifacts.mjs` doesn't check the seven new headers.** I didn't edit that file, because it was outside this task's scope. Add `hploc-cpu.js`, `lbvh-cpu.js`, `query/shapes.js`, `query/cpu-mesh-bvh.js`, `query/debug.js`, `query/three-mesh-bvh-format.js` and `trace/wgsl.js` to `requiredLicenseText`.
- **Root `LICENSE` holder.** "Dennis Smolek" is valid. Some pmndrs repos name "Poimandres" instead. That is Dennis's call.
- **Two copyright lines for tinybvh.** The header of `gpu-hploc-wgsl.ts` quotes `tiny_bvh.h`'s own notice ("2024-2026, Jacco Bikker / Breda University of Applied Sciences"). `licenses/tinybvh.txt` is the repo's `LICENSE` ("2024 Jacco Bikker"). Both are upstream text, so nothing needs to change.
- **The examples site.** Vite keeps the `/*!` comments, so the ported library files carry their licences in the site's bundles. The example ports other than `select.ts` have only a `/**` credit, which minification drops. They don't ship in the package. If the site should carry the notices, a licence link on the site is enough.
