## TraceBatchKernel

For rays you have in a buffer (picking, AO samples, visibility tests), the package has its own kernel: one dispatch for
any number of rays, group 0 the scene, group 1 the rays and results. One kernel serves any number of scenes.

{/* snippet: batch */}
```ts
import { HIT_RECORD_BYTES, packRays, RAY_BYTES, TraceBatchKernel } from '@pmndrs/bvh';

const kernel = await TraceBatchKernel.create(device, {
    triangleLeaves: trees.triangleLeaves,
    positionLayout: trees.positionLayout,
    nodeFormat: trees.nodeFormat,
    hitNormal: true, // 40-byte records with material and normal; false: 24 bytes
});
const count = 4096;
const rays = device.createBuffer({ size: count * RAY_BYTES, usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_DST });
const results = device.createBuffer({ size: count * HIT_RECORD_BYTES, usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC });
const shadowResults = device.createBuffer({ size: count * 4, usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC });
device.queue.writeBuffer(rays, 0, packRays(Array.from({ length: count }, (_, i) => ({ origin: [i * 0.01, 1, 5], direction: [0, 0, -1], tMin: 0, tMax: 1e30 }))));

const encoder = device.createCommandEncoder();
kernel.encode(encoder, trees.traceBuffers, { mode: 'closest', rays, results, count });
kernel.encode(encoder, trees.traceBuffers, { mode: 'any', rays, results: shadowResults, count, mask: 0x1 }); // one u32 per ray, 1 = blocked
device.queue.submit([encoder.finish()]);
```

- **Rays:** 32 bytes each (`RAY_BYTES`), as `BvhRay`: origin, `tMin`, direction, `tMax`. `packRays` writes them from
  `{ origin, direction, tMin, tMax }` objects.
- **Closest-hit records** (`hitNormal: true`, the default): 40 bytes (`HIT_RECORD_BYTES`), words in `HIT_RECORD_WORD`:
  0 `t`, 1 `instance`, 2 `triangle`, 3 `frontFace` (0 or 1), 4-5 `barycentrics`, 6 `material`, 7-9 `normal`.
- **Compact records** (`hitNormal: false`): 24 bytes (`HIT_RECORD_COMPACT_BYTES`), words 0-5 only.
- **Any-hit results:** one `u32` per ray, 1 when blocked.
- **Masks:** one ray mask per batch (`mask`), a uniform; there is no per-ray mask buffer.
- **Timing:** pass `timestampWrites` to time the dispatch's pass.
- **Sizes:** `encode` throws a `RangeError` when `rays` or `results` holds fewer than `count` items.

The 40-byte record is the default: a hit carries its material and normal unless you say otherwise. It has a cost on
NVIDIA. Against the 24-byte record, closest-hit rays traced at 0.88-0.92x on Sponza and 0.93-0.94x on Bistro interior
on the RTX 3060 Laptop, a 6-12% cost (Windows, headless Chrome 157, 2026-11-13, surface and air rays, instanced and
merged trees, the median of three runs of 5 paired rounds). On the Apple M5 it cost nothing measurable: 0.96-1.15x,
medians 1.02-1.11 in favour of the bigger record (indicative). Intel has not run it.

So a shadow or occlusion pass that reads neither material nor normal should pass `hitNormal: false`, or trace any-hit
rays, which write one word per ray.

`batchKernelWgsl(mode, options)` gives the kernel's WGSL, for a pipeline of your own.

## The CPU walk

`createCpuTracer(scene)` is the WGSL walk, step for step, in TypeScript, over the same buffers (`TraceSceneData`, as
`buildTraceScene` or `assembleTraceScene` return it). It runs in Node, so tests cover the walk and the layout without a
GPU.

{/* snippet: cpu-walk */}
```ts
import { buildMeshBvhWithTinyBvh, buildTraceScene, createCpuTracer, createTinyBvhBuilder, IDENTITY_TRANSFORM } from '@pmndrs/bvh';

const tiny = await createTinyBvhBuilder();
const scene = await buildTraceScene([geometry], [{ meshIndex: 0, instanceIndex: 0, objectToWorld: IDENTITY_TRANSFORM }], {
    build: (mesh) => buildMeshBvhWithTinyBvh(mesh, tiny),
});
// The WGSL walk, step for step in TypeScript, over the same buffers.
const tracer = createCpuTracer(scene);
const hit = tracer.closest({ origin: [0, 0, 5], direction: [0, 0, -1], tMin: 0, tMax: 1e30 });
const blocked = tracer.any({ origin: [0, 0, 5], direction: [0, 0, -1], tMin: 0, tMax: 1e30 }, { mask: 0x1 });
```

- `closest(ray, { mask, side, stats })` returns `{ t, instanceIndex, triangleIndex, u, v, frontFace, material, normal }`
  or null. `any(ray, { mask })` returns a boolean.
- `side` (CPU only: the WGSL walk has no side option) culls front or back faces: `CPU_TRACE_FRONT_SIDE`,
  `CPU_TRACE_BACK_SIDE`, `CPU_TRACE_DOUBLE_SIDE` (the default, as the GPU walk).
- `stats` (from `newTraceStats()`) counts nodes visited, triangles tested and the deepest stack.
- `createCpuTracer(scene, { triangleFilter, rayMasks })` takes the filter as a TypeScript function.

For queries on one mesh (raycasts with sides, shapecasts, closest points), use [`CpuMeshBvh`](/cpu-queries/raycast).
