The examples live in [`examples/`](https://github.com/pmndrs/bvh/tree/main/examples): a Vite site where each page has
its source beside it and a shared overlay (which builder ran and why, build ms, SAH cost, depth, bytes, Mrays/s, a
frame-time graph). Most pages take a glTF dropped onto them.

```bash
pnpm examples:dev       # http://localhost:5310
pnpm examples:build     # examples/dist, a static site
pnpm examples:smoke     # every example in headless Chrome, each checking one thing it shows
```

## Vanilla WebGPU

Raw WebGPU and `@pmndrs/bvh` only: no three, no engine.

| Page | Shows |
| --- | --- |
| [`vanilla/hello`](https://github.com/pmndrs/bvh/tree/main/examples/vanilla/hello) | The smallest use: `createMeshLayoutBuilder` picks the builder and says why, the tree's boxes in a line pass, a picking ray, and a batch of rays whose hits are drawn straight from the GPU buffer. |
| [`vanilla/raytrace`](https://github.com/pmndrs/bvh/tree/main/examples/vanilla/raytrace) | The WGSL walk in the page's own compute kernel: one ray per pixel, shown by normal, material, instance or distance, any-hit shadows; switch tinybvh, H-PLOC and LBVH live. |
| [`vanilla/instances`](https://github.com/pmndrs/bvh/tree/main/examples/vanilla/instances) | `SceneTrees` with thousands of moving instances, runtime adds and removals, GPU first trees swapped for tinybvh's, and picking. |
| [`vanilla/builders`](https://github.com/pmndrs/bvh/tree/main/examples/vanilla/builders) | tinybvh, H-PLOC and LBVH side by side on one mesh: build ms, SAH, depth, bytes, Mrays/s on the same rays. |

## three.js

| Page | Shows |
| --- | --- |
| [`three/raycast`](https://github.com/pmndrs/bvh/tree/main/examples/three/raycast) | `acceleratedRaycast` against three's `Mesh.raycast`, live, and a GPU batch of thousands of rays in one dispatch. |
| [`three/pathtracer`](https://github.com/pmndrs/bvh/tree/main/examples/three/pathtracer) | A small TSL compute path tracer over `BvhTraceNodes`: closest hits, any-hit shadows, progressive accumulation. |
| [`three/skinned`](https://github.com/pmndrs/bvh/tree/main/examples/three/skinned) | `BvhPosePass` skins on the GPU, `SceneTrees` refits, and GPU picking hits the moving characters. |
| [`three/instances`](https://github.com/pmndrs/bvh/tree/main/examples/three/instances) | 6,000 `InstancedMesh` and 3,000 `BatchedMesh` instances moving, with a top-level refit every frame and picking. |
| [`three/load-gltf`](https://github.com/pmndrs/bvh/tree/main/examples/three/load-gltf) | Fast first trees on a real glTF: GPU H-PLOC, then tinybvh from the worker pool, with a per-mesh timeline. |
| [`three/inspector`](https://github.com/pmndrs/bvh/tree/main/examples/three/inspector) | tinybvh, H-PLOC and LBVH on one mesh: build times, SAH, depth, bytes, `MeshBVHHelper` and a heat map of nodes per ray. |
