@pmndrs/bvh examples

Engine-free WebGPU BVHs: GPU H-PLOC and LBVH builders, tinybvh in WebAssembly and a worker pool, GPU refits, and a WGSL walk. Every page shows which builder ran and why, build times, tree stats, ray rates and a frame-time graph. Drop a glTF on any page, or pass ?model=downloads/…/scene.gltf to load one from BVH_ASSETS_DIR.
